### 🛡️ Segurança

Segurança faz parte do desenvolvimento dos meus projetos desde a autenticação até a infraestrutura.

| Área | Práticas e conceitos |
| --- | --- |
| **Autenticação** | Argon2id, sessões server-side, 2FA, passkeys / WebAuthn, Google OAuth e recuperação segura de senha |
| **Aplicação Web** | CSRF, CORS, CSP, rate limiting, proteção contra brute force, validação de dados e headers de segurança |
| **Banco de Dados** | Prepared statements e proteção contra SQL Injection |
| **Infraestrutura** | HTTPS / TLS, HSTS, firewall, reverse proxy com Nginx e hardening de VPS |
| **Auditoria** | Logs seguros, OWASP e testes com OWASP ZAP |

> **Security-focused web development:** segurança integrada ao desenvolvimento, à autenticação e à infraestrutura.
